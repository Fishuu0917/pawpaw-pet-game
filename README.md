# PawPaw 宇宙寵物店

這是以原生 HTML、CSS、JavaScript 製作的單頁電子寵物遊戲。完整網站只有一份 `index.html`，不需要安裝套件、Node.js 或啟動開發伺服器。

## 開始遊玩

直接用瀏覽器開啟 `index.html`，選擇一位夥伴即可開始。遊戲進度會自動儲存在目前瀏覽器的 `localStorage`。

## GitHub Pages 發布

1. 將專案推送到 GitHub 的 `main` 分支。
2. 在 repository 的 **Settings → Pages** 將來源設為 **GitHub Actions**。
3. `Deploy PawPaw to GitHub Pages` 工作流程會將單檔網站發布。也可以在 Actions 手動執行工作流程。

網站的遊戲邏輯、樣式與畫面都包含在 `index.html`，不需要設定部署路徑或外部服務。

## 遊戲規則

每次有效照顧操作獲得的 EXP 依序為餵食 +5、玩耍 +15、摸摸 +3、睡覺 +5，沒有每日 EXP 上限；隨機星星糖另加 5 EXP。第一級升級需要 100 EXP，之後每級需求增加 50 EXP。餵食消耗 5 點可用體力並增加 20 飽食度；飽食度滿時不能餵食。玩耍消耗 15 點可用體力及 10 點飽食度；摸摸消耗 3 點可用體力且不改變飽食度；睡覺恢復 25 點體力、消耗 5 點飽食度，使用後冷卻 3 分鐘。一般體力不足時，各項需消耗體力的照顧操作會先扣除一般體力，再由影片加成體力補足；「追逐流星」事件也使用相同規則。成功互動後有 15% 機率遇到宇宙事件。寵物狀態不會因時間下降。影片獎勵按鈕會隨機開啟三支指定 YouTube 影片之一，以 80%／18%／2% 機率累積 50／75／100 點額外體力；額外體力可超過一般體力的 100 上限。影片冷卻 3 分鐘，每日本機日曆日最多成功領取 3 次。
